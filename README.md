# appsec-toolkit

A Python-based toolkit for Application Security Engineers, Penetration Testers, and Security Researchers.

## Features

- Security Header Analysis
- JWT Decoder
- SSL/TLS Scanner
- HTTP Method Enumeration
- Hash Identifier
- Password Strength Checker
- Base64 Encoder/Decoder
- CVSS Calculator
- OWASP Top 10 Mapping
- HTML Report Generation

## Installation

---bash
git clone https://github.com/yourusername/appsec-toolkit.git
cd appsec-toolkit
pip install -r requirements.txt
```

## Usage

---bash
python app.py --headers https://example.com
---
